# Screenshots

Drop the README screenshots here. Filenames are referenced by the root `README.md`.

| File | What to capture | Priority |
| --- | --- | --- |
| `dashboard.png` | The full dashboard. Run `make dashboard`, then screenshot the page. | Required |
| `rule-with-references.png` | A close-up of one rule card with its reference links beneath it. | Nice to have |

Tips:
- Use a wide window (about 1000px) so the rule cards are readable.
- Light or dark is fine; the dashboard follows your system theme.
- PNG, trimmed to the content.
