# Elixir Standards

How we write Elixir at Euna Payments. These conventions capture the judgment that tools
like `mix format` and Credo cannot, and they guide the Credo checks we add per repo.

## Conventions

- [Property testing](property-testing.md)
- [Unit testing](unit-testing.md) - tags, context, and DRY test patterns.
- [Application configuration](application-configuration.md)
- [Control structures](control-structures.md)
- [Modules](modules.md) - namespacing, aliasing, and single responsibility.
- [Naming](naming.md) - names for modules, functions, variables, and files.
- [Idioms](idioms.md) - the preferred, concrete way to write common things.
- [Anti-patterns](anti-patterns.md) - concrete patterns to avoid.
- [Principles](principles.md) - the design philosophy behind the rules.
- [Tooling](tooling.md) - deps, formatter, Credo, Dialyzer, and CI configuration.
